# Datasheets and official documentation {#witmotion_docs}

The library is developed according to the specifications released by Witmotion; the presented snapshot has a download date of 23.02.2022. The official website `https://wiki.wit-motion.com` is not always accessible, so the PDF snapshots are placed under [IPFS web directory](https://bafybeigoaszhxyreuqiu326gjrwc7kljuwr7mbcfq5f63jfiti44lsdovq.ipfs.twdragon.net) maintained by @twdragon.

- [WT61C 3-Axis Combined Accelerometer/Gyroscope Sensor](https://bafybeigoaszhxyreuqiu326gjrwc7kljuwr7mbcfq5f63jfiti44lsdovq.ipfs.twdragon.net/Witmotion%20WT61C%20Datasheet.pdf)
- [WT31N 3-Axis Accelerometer/Gyroscope Sensor](https://bafybeigoaszhxyreuqiu326gjrwc7kljuwr7mbcfq5f63jfiti44lsdovq.ipfs.twdragon.net/Witmotion%20WT31N%20Datasheet.pdf)
- [WT901C 9-Axis Enclosed Inclinometer Sensor](https://bafybeigoaszhxyreuqiu326gjrwc7kljuwr7mbcfq5f63jfiti44lsdovq.ipfs.twdragon.net/Witmotion%20WT901C%20Datasheet.pdf)

- [HWT905 RS232/TTL 9-Axis IP67-Enclosed Combined IMU/Magnetometer/Altimeter/Inclinometer](https://bafybeigoaszhxyreuqiu326gjrwc7kljuwr7mbcfq5f63jfiti44lsdovq.ipfs.twdragon.net/Witmotion%20HWT905%20RS232%20Datasheet.pdf)
